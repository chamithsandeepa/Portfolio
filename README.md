## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code, Sublime Text, etc.) for editing
- Git (for version control)

### Installation

1. **Clone the repository**
```bash
   git clone https://github.com/chamithsandeepa/Portfolio.git
   cd Portfolio
```

2. **Open in browser**
   
   Simply open `index.html` in your web browser:
   - Double-click `index.html`, or
   - Right-click and select "Open with" your preferred browser, or
   - Use a local development server

3. **Using Live Server (Recommended)**
   
   If you have VS Code with Live Server extension:
```bash
   # Right-click on index.html and select "Open with Live Server"
   # Or use the shortcut: Alt + L + O
```

4. **Access the website**
   - Local: `file:///path/to/index.html`
   - Live Server: `http://localhost:5500` (or your configured port)
   - Live Demo: `https://portfolio-jq3c.vercel.app/`

## 🎨 Customization Guide

### Updating Content

1. **Personal Information**
   - Edit `index.html` for hero section content
   - Update `about.html` with your background
   - Modify `contact.html` with your contact details

2. **Styling**
   - Main colors: Edit CSS variables in `css/style.css`
   - Fonts: Change font families in the CSS file
   - Layout: Modify grid/flexbox properties as needed

3. **Images**
   - Replace images in `assets/images/` folder
   - Update image paths in HTML files
   - Optimize images for web performance

### Adding New Sections

```html
<!-- Example: Adding a new section -->
<section id="new-section" class="section">
  <div class="container">
    <h2>Section Title</h2>
    <div class="content">
      <!-- Your content here -->
    </div>
  </div>
</section>
```
